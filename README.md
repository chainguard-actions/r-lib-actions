# r-lib/actions

Action to check R package with rcmdcheck. Assumes that rcmdcheck has already been installed.

Hardened by [Chainguard](https://www.chainguard.dev) from the upstream action at [https://github.com/r-lib/actions](https://github.com/r-lib/actions).
